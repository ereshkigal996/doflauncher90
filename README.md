# DNF轮回启动器

![Version](https://img.shields.io/badge/version-3.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Windows-orange)

DNF90单机版多功能启动器，集成账号管理、GM工具、客户端补丁安装等功能。

## ✨ 功能特性

### 核心功能
- 🎮 一键启动游戏
- 👤 账号注册与登录
- 🖥️ 服务端管理（启动/停止/重启）
- 🔧 客户端补丁安装
- 📦 PVF文件校验与替换
- 💾 数据备份与恢复

### 内置工具
- 🛠️ **GM工具** - 角色管理、背包管理、道具发放、装备强化增幅
- 👥 **账号管理工具** - 账号查询、修改密码、批量操作

### 界面特性
- 🎨 Win11黑暗模式配色
- 📐 一体化无边框窗口
- 🔤 思源黑体字体
- 🖱️ 自定义标题栏（双击最小化）
- 📊 实时操作日志

## 📦 安装

### 系统要求
- Windows 10/11
- .NET Framework 4.5+（运行库已内置）
- 管理员权限

### 安装步骤
1. 下载 `DNFLauncher_3.0_release_installer.exe`
2. 右键以管理员身份运行
3. 选择安装目录（默认：`C:\Program Files\DNFLauncher`）
4. 等待安装完成
5. 启动程序，设置服务端路径和客户端路径
6. 安装客户端补丁
7. 启动服务端，注册账号并登录

## 📁 目录结构

```
DNFLauncher/
├── launcher.exe          # 启动器主程序
├── config/               # 配置文件目录
│   ├── config.lau        # 主配置文件
│   └── accounts.dat      # 账号密码文件（加密）
├── fonts/                # 字体文件
│   └── NotoSansSC-Bold.ttf
├── lib/                  # 启动器运行库
├── backup/               # 数据备份目录
├── temp/                 # 临时文件目录
└── module/               # 模块目录
    ├── accmg.exe         # 账号管理工具
    ├── gmtool.exe        # GM工具
    ├── config/           # 模块配置目录
    └── lib/              # 模块运行库
```

## 🎮 使用说明

### 首次使用
1. 启动launcher.exe
2. 在路径设置页面设置服务端路径和客户端路径
3. 点击"安装客户端补丁"
4. 点击"确认"进入主页面
5. 点击"启动服务"等待服务端启动
6. 点击"账号登录"注册或登录账号
7. 登录成功后自动启动游戏

### GM工具使用
1. 在主页面点击"GM工具"
2. 选择角色进行管理
3. 可以发放道具、修改装备、调整金币点券等

### 数据备份
1. 在主页面点击"存档管理"
2. 点击"备份"创建数据备份
3. 可以设置自动备份（定时/关闭服务端时）

## 🔧 配置说明

### 配置文件
配置文件位于 `config/config.lau`，包含以下字段：
- `launcher` - 启动器配置（路径、数据库模式等）
- `gmtool` - GM工具配置

### 数据库模式
支持两种数据库模式：
- **MySQL** - 默认模式，适合大多数用户
- **SQLite** - 轻量级模式，无需额外安装MySQL

## ❓ 常见问题

### Q: 启动器无法启动服务端？
A: 请检查服务端路径是否正确，确认服务端文件完整，尝试重启电脑后再次启动。

### Q: 游戏启动后显示"服务器连接不上"？
A: 请确认服务端已成功启动，检查服务端IP配置是否正确，确认防火墙未阻止游戏进程。

### Q: 无法登录账号？
A: 请确认数据库已正常启动，检查账号密码是否正确，尝试重新注册账号。

### Q: 安装客户端补丁失败？
A: 请确认客户端路径设置正确，确认游戏已完全退出，尝试以管理员身份运行启动器。

更多问题请查看 [常见问题.md](常见问题.md)
