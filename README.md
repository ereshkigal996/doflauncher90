## 📖 项目简介

DNF轮回启动器是一个专为《地下城与勇士》90单机版量身打造的多功能游戏管理平台。项目采用模块化设计理念，将账号管理、服务端控制、客户端配置、GM工具等核心功能有机整合，为玩家提供一站式的单机游戏体验。

本启动器经过多个版本的迭代优化，目前已具备完善的功能体系和稳定的运行性能。无论是新手玩家还是资深管理员，都能通过直观的界面快速上手，轻松管理自己的单机游戏环境。

## ✨ 核心功能

### 🎮 游戏管理
- **一键启动游戏** - 智能检测游戏环境，快速启动游戏客户端
- **服务端管理** - 实时监控服务端状态，支持启动、停止、重启等操作
- **客户端补丁安装** - 自动化的补丁检测与安装，确保游戏文件完整性

### 👤 账号系统
- **账号注册** - 便捷的账号创建流程，支持自定义角色名
- **账号登录** - 安全可靠的本地认证机制
- **账号管理工具** - 完善的账号信息管理，包括密码修改、角色查看等功能

### 🛠️ 开发者工具
- **GM工具** - 强大的游戏管理员工具集
  - 角色管理 - 创建、删除、修改角色信息
  - 背包管理 - 查看和编辑角色物品栏
  - 道具发放 - 批量生成游戏道具
  - 属性调整 - 修改角色基础属性
- **PVF文件校验** - 自动检测PVF文件完整性
- **数据备份恢复** - 一键备份重要游戏数据，支持定时自动备份

### 🔄 系统功能
- **自动更新** - 启动器自动检测并下载最新版本
- **配置管理** - 集中管理所有游戏相关设置
- **日志监控** - 实时查看服务端运行日志

## 📁 目录结构

```
DNFLauncher/
├── launcher.exe              # 启动器主程序
├── updater.exe               # 自动更新程序（与launcher共用lib库）
├── config/                   # 配置文件目录
│   ├── server_config.ini     # 服务端配置
│   ├── client_config.ini     # 客户端配置
│   └── user_config.ini       # 用户配置
├── fonts/                    # 字体文件目录
│   └── game_fonts.ttf        # 游戏专用字体
├── lib/                      # 运行库目录
│   ├── launcher_lib.dll      # 启动器核心库
│   ├── updater_lib.dll       # 更新程序库
│   └── third_party/          # 第三方依赖库
├── backup/                   # 数据备份目录
│   ├── accounts/             # 账号数据备份
│   ├── characters/           # 角色数据备份
│   └── world_data/           # 世界数据备份
└── module/                   # 功能模块目录
    ├── accmg.exe             # 账号管理工具
    ├── gmtool.exe            # GM游戏管理工具
    ├── config/               # 模块配置目录
    │   ├── accmg_config.ini  # 账号管理工具配置
    │   └── gmtool_config.ini # GM工具配置
    └── lib/                  # 模块专用运行库
```

## 🚀 快速开始

### 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 7 64位 | Windows 10/11 64位 |
| 内存 | 4GB | 8GB及以上 |
| 硬盘空间 | 20GB | 50GB及以上 |
| .NET Framework | 4.5 | 4.8及以上 |

### 安装步骤

1. **下载安装包**
   - 访问项目发布页面下载最新版本的安装包
   - 文件名格式：`DNFLauncher_x.x.x_release_installer.exe`

2. **运行安装程序**
   - 双击下载的安装包文件
   - 根据安装向导提示选择安装路径
   - 建议安装在非系统盘（如 D:\DNFLauncher）

3. **首次配置**
   - 启动 `launcher.exe`
   - 在设置界面配置以下参数：
     - **服务端路径** - 选择DNF服务端程序所在目录
     - **客户端路径** - 选择DNF客户端程序所在目录
     - **数据存储路径** - 选择游戏数据保存位置

4. **安装客户端补丁**
   - 在启动器主界面点击"补丁管理"
   - 选择需要安装的补丁文件
   - 点击"安装"等待补丁应用完成

5. **启动游戏**
   - 确保服务端已启动（在启动器中点击"启动服务端"）
   - 点击"启动游戏"按钮进入游戏

### 日常使用流程

```
启动启动器 → 检查服务端状态 → 登录账号 → 启动游戏 → 享受游戏
```

## 📖 使用指南

### 首次使用

首次启动启动器时，系统会引导您完成初始配置。请按照以下步骤操作：

1. **环境检测** - 启动器自动检测系统环境
2. **路径设置** - 指定服务端和客户端的安装路径
3. **补丁安装** - 根据提示安装必要的客户端补丁
4. **服务端启动** - 点击"启动服务端"按钮
5. **账号注册** - 使用账号管理工具注册新账号
6. **登录游戏** - 在登录界面输入账号信息

### PVF文件管理

PVF（Player Value File）是DNF的核心数据文件，启动器提供了便捷的PVF管理功能：

- **文件校验** - 自动检测PVF文件完整性
- **版本对比** - 显示当前PVF与标准版本的差异
- **一键替换** - 快速替换为指定版本的PVF文件

### 数据备份

强烈建议定期备份游戏数据，防止意外数据丢失：

- **手动备份** - 点击"备份"按钮进行即时备份
- **自动备份** - 在设置中启用定时自动备份功能
- **恢复数据** - 从备份列表中选择需要恢复的备份点

### 版本更新

启动器支持自动更新功能：

1. 启动器启动时自动检测新版本
2. 发现新版本时弹出更新提示
3. 用户确认后自动下载并安装更新
4. 更新完成后需重启启动器

## ❓ 常见问题

### 启动器无法启动服务端
请检查以下配置：
- 服务端路径是否正确设置
- 服务端程序是否完整无损
- 端口是否被其他程序占用
- 服务端依赖文件是否齐全

### 游戏连接服务器失败
- 确认服务端已正常启动
- 检查防火墙是否阻止了游戏连接
- 验证网络配置参数是否正确
- 尝试重启启动器和服务端

### 无法注册或登录账号
- 检查数据库服务是否正常运行
- 确认账号数据目录有写入权限
- 查看日志文件获取详细错误信息
- 验证账号是否符合命名规范

### 补丁安装失败
- 确认补丁文件完整性
- 关闭杀毒软件后重试
- 检查客户端路径权限
- 确认补丁版本与客户端兼容

### GM工具连接失败
- 检查数据库连接配置
- 确认GM工具版本与服务端匹配
- 查看网络端口是否开放
- 验证管理员权限是否正确
