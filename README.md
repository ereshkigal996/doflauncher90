# DNF轮回启动器

## 简介
DNF轮回启动器是一个专为DNF90单机版设计的多功能启动器，集成了账号管理、GM工具、客户端补丁安装等功能。

## 主要功能
- 一键启动游戏
- 账号注册与登录
- 服务端管理（启动/停止）
- 客户端补丁安装
- PVF文件校验与替换
- 数据备份与恢复
- GM工具（角色管理、背包管理、道具发放等）
- 账号管理工具
- 自动更新

## 目录结构
```
DNFLauncher/
├── launcher.exe          # 启动器主程序
├── updater.exe           # 自动更新程序（共用lib运行库）
├── config/               # 配置文件目录
├── fonts/                # 字体文件
├── lib/                  # 运行库（launcher和updater共用）
├── backup/               # 数据备份目录
└── module/               # 模块目录
    ├── accmg.exe         # 账号管理工具
    ├── gmtool.exe        # GM工具
    ├── config/           # 模块配置目录
    └── lib/              # 模块运行库
```

## 使用说明
1. 首次运行请设置服务端路径和客户端路径
2. 安装客户端补丁
3. 启动服务端
4. 注册账号并登录游戏
