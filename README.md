## 📦 安装说明

### 系统要求
- **操作系统**：Windows 10 / Windows 11（64位）
- **运行环境**：无需额外安装运行库（已内置）
- **磁盘空间**：至少500MB可用空间
- **权限要求**：管理员权限

### 安装步骤

1. **下载安装包**
   - 文件名：`DNFLauncher_2.9.7_release_installer.exe`
   - 大小：约44MB

2. **运行安装程序**
   - 右键点击安装包，选择"以管理员身份运行"
   - 如果弹出用户账户控制提示，点击"是"

3. **选择操作**
   - 首次安装：选择"安装 DNF轮回启动器"
   - 已安装更新：选择"更新现有安装"
   - 需要卸载：选择"卸载 DNF轮回启动器"

4. **选择安装目录**
   - 默认目录：`C:\Program Files\DNFLauncher`
   - 建议使用默认目录，避免中文路径问题

5. **选择组件**
   - 完整安装：推荐，包含所有功能（GM工具、账号管理工具、文档）
   - 只安装登录器：仅核心功能

6. **完成安装**
   - 等待安装完成
   - 可选创建桌面快捷方式
   - 安装完成后手动启动程序

### 首次使用配置

1. **启动程序**
   - 双击桌面快捷方式，或从开始菜单启动
   - 程序会自动请求管理员权限

2. **设置服务端路径**
   - 首次启动会要求设置服务端路径
   - 选择DNF90服务端根目录（包含runtime文件夹的目录）

3. **设置客户端路径**
   - 设置DNF客户端根目录（包含DNF.exe的目录）

4. **安装客户端补丁**
   - 点击"安装客户端补丁"按钮
   - 等待补丁安装完成
   - 选择数据库模式（推荐MySQL）

5. **启动服务**
   - 点击"启动服务"按钮
   - 等待服务端启动完成（约30-60秒）

6. **登录游戏**
   - 输入账号密码，点击"登录"
   - 或点击"注册"创建新账号
   - 游戏启动后即可开始游戏

## 🎮 使用指南

### 启动器主界面

| 按钮 | 功能 |
|------|------|
| **启动服务** | 启动DNF90服务端 |
| **停止服务** | 停止DNF90服务端 |
| **安装补丁** | 安装/更新客户端补丁 |
| **账号登录** | 进入账号登录页面 |
| **数据迁移** | 数据库备份/恢复 |
| **存档管理** | 多版本存档管理 |
| **运行GM工具** | 启动GM管理工具 |
| **重设路径** | 重新设置服务端和客户端路径 |

### 状态栏说明

- **左边**：显示用户操作记录（如"启动服务"、"停止服务"、"返回"等）
- **右边**：显示版本号（2.9.7_release）
- **操作记录自动去除"点击"字样**，显示更简洁

### GM工具使用

1. **启动GM工具**
   - 在启动器主界面点击"运行GM工具"
   - 或直接运行 `module/gmtool.exe`

2. **选择角色**
   - 在角色列表中选择要操作的角色
   - 支持按账号名、角色名搜索

3. **功能模块**
   - **角色管理**：调整等级、点券、金币、黑钻
   - **背包管理**：查看和删除背包物品
   - **道具发放**：发送物品到角色邮箱
   - **邮件管理**：查看和删除邮件
   - **装备管理**：发送带强化增幅的装备

4. **预设功能使用**
   - 点击道具发放模块右下角的"预设"按钮
   - 设置金币方向（增加/减少）和点券方向（充值/回收）
   - 点击"保存"保存预设
   - 之后调整金币/点券时，弹窗仅显示"确定"/"取消"按钮

5. **发放装备步骤**
   - 切换到"道具发放"页面
   - 搜索要发放的装备（如"刺骨"）
   - 选择装备类型为"装备"
   - 设置强化等级（如12）
   - 设置增幅等级（如12）
   - 选择异次元能力（如力量）
   - 点击"发送"按钮
   - 物品会通过邮件发送到角色邮箱

### 账号管理工具

1. **启动方式**
   - 在启动器登录页面输入 `iamgod`（账号和密码都输入）
   - 程序会自动启动账号管理工具

2. **功能说明**
   - 查看所有注册账号
   - 添加新账号
   - 修改账号密码
   - 删除账号
   - 批量操作
   - 分组管理

## ⚠️ 注意事项

### 重要提醒

1. **管理员权限**
   - 启动器必须以管理员权限运行
   - 否则可能无法启动服务端或修改游戏文件

2. **服务端路径**
   - 服务端路径必须是包含 `runtime` 文件夹的根目录
   - 不要选择到runtime文件夹内部

3. **客户端路径**
   - 客户端路径必须是包含 `DNF.exe` 的根目录
   - 安装补丁前请确保游戏已完全关闭

4. **数据备份**
   - 建议定期使用"数据迁移"功能备份数据库
   - 重要操作前建议先备份
   - 可设置自动备份功能

5. **邮件系统**
   - 所有发放的物品都通过邮件发送
   - 发放后请在游戏内查收邮件
   - 如果邮箱打不开，可能是异常邮件导致，使用GM工具清理

### 常见问题

**Q：启动服务后提示"服务启动失败"怎么办？**
A：
1. 检查服务端路径是否正确
2. 检查是否有其他程序占用端口
3. 尝试重启电脑后再启动
4. 查看日志区的详细错误信息

**Q：GM工具提示"no such table: dnf_characters"怎么办？**
A：
1. 确保已经安装客户端补丁
2. 确保服务端已经启动
3. 2.9.7版本已默认使用MySQL模式，如仍有问题请检查数据库配置

**Q：GM工具物品名称显示为ID怎么办？**
A：
1. 2.9.7版本已使用PVF解析模式，无需items.json
2. 确保服务端路径配置正确
3. 如仍有问题，请重新安装程序

**Q：发放的装备无法使用怎么办？**
A：
1. 确保装备类型选择正确
2. 确保强化和增幅等级在合理范围内
3. 尝试重新发放
4. 如仍有问题，请使用GM工具删除异常邮件

**Q：安装后无法启动程序怎么办？**
A：
1. 右键点击程序，选择"以管理员身份运行"
2. 检查杀毒软件是否误删了文件
3. 尝试重新安装
4. 确保系统是64位Windows 10/11

**Q：如何更新到新版本？**
A：
1. 下载新版本安装包
2. 运行安装程序，选择"更新现有安装"
3. 等待更新完成
4. 用户数据和配置会自动保留

**Q：状态栏显示的操作记录是什么意思？**
A：
- 状态栏左边显示用户最近的操作记录
- 例如点击"启动服务"后，状态栏显示"启动服务"
- 自动去除"点击"字样，显示更简洁
- 状态栏右边显示当前版本号

**Q：GM工具的预设功能怎么用？**
A：
1. 点击道具发放模块右下角的"预设"按钮
2. 设置金币方向（增加/减少）和点券方向（充值/回收）
3. 点击"保存"保存预设
4. 之后调整金币/点券时，弹窗仅显示"确定"/"取消"按钮
5. 按预设方向执行操作，无需每次选择方向
