## 使用方法

### 在GM工具中发送物品

1. 打开GM工具，进入"道具发放"模块
2. 在搜索框中输入物品名称或物品ID
3. 选择要发送的物品
4. 设置物品数量（消耗品可设置数量，装备数量固定为1）
5. 如需为装备添加强化/增幅等级，展开强化设置区域
6. 点击"发送"按钮，物品将通过邮件发送给指定角色

### 搜索技巧

- **按名称搜索**：输入物品名称的关键词，如"复活币"、"深渊票"、"史诗"
- **按ID搜索**：直接输入物品ID数字
- **按类型筛选**：使用物品类型下拉菜单筛选特定类型的物品

### 注意事项

1. **装备强化/增幅**：仅装备类物品可设置强化/增幅等级，时装、称号、宠物装备不可设置
2. **物品数量**：消耗品可设置任意数量（受堆叠上限限制），装备数量固定为1
3. **邮件发送**：所有物品通过邮件发送，角色需要在游戏中接收邮件
4. **不可用物品**：部分任务物品、废品等可能无法在游戏中正常使用，请谨慎发送
5. **数据库类型**：确保GM工具的数据库类型（MySQL/SQLite）与服务端一致
