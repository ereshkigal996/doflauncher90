# 打包和安装配置说明

## 固定规则

### 1. 程序打包模式
- **固定模式**：onedir（目录模式）
- **不使用**：onefile（单文件模式）
- **原因**：onedir模式启动更快，便于更新单个文件，运行库管理更清晰

### 2. 安装程序模式
- **默认模式**：多功能版（安装/更新/卸载）
- **功能**：
  - 未安装时：只显示"安装"选项
  - 已安装时：显示"安装"、"更新现有安装"、"卸载"三个选项
- **安装脚本**：`pip/installer/launcher_2.9.5_multifunction_installer.iss`

### 3. 发布目录结构
- **发布目录名称**：`DNFLauncher`
- **位置**：`release/DNFLauncher/`

### 4. 程序放置规则
- **launcher主程序**：放在发布目录根目录下
  - `DNFLauncher/launcher.exe`
  - `DNFLauncher/lib/`（运行库）
- **其他程序**：都放在`发布目录/module/`下
  - `DNFLauncher/module/gmtool.exe`（GM工具）
  - `DNFLauncher/module/accmg.exe`（账号管理工具）
  - `DNFLauncher/module/items.json`（物品数据）
  - `DNFLauncher/module/lib/`（module运行库）

## 打包命令

### 打包启动器
```bash
cd pip/launcher
pyinstaller launcher.spec --clean
```

### 打包GM工具
```bash
cd pip/gmtool
pyinstaller gmtool.spec --clean
```

### 打包账号管理工具
```bash
cd pip/accmg
pyinstaller accmg.spec --clean
```

### 打包安装包
```bash
"C:\Program Files\Inno Setup 7\ISCC.exe" pip/installer/launcher_2.9.5_multifunction_installer.iss
```
