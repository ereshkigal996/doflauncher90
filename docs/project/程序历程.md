# DNF轮回启动器 程序历程

## 版本说明

- **正式版本命名格式**：`DNFLauncher_<主版本>.<次版本>.<修订版本>_release_installer`
- **测试版本命名格式**：`launcher_<版本号>_beta<逻辑改动次数>_build<界面改动次数>`
- **正式版本号计算规则**：测试开始版本号 + beta计数 + build计数
  - 例如：开始版本1.4.1，测试版本1.4.1beta4build6 → 正式版1.8.7

### 2.9 版本系列

#### 2.9.0 技术债务修复版本
**发布时间**：2026年9月1日
**主要更新**：

**技术债务修复（5项）**：
1. **单实例运行限制**
   - QSharedMemory互斥机制
   - 多实例启动时提示"程序已运行"并退出
   - 防止多实例冲突导致的数据损坏

2. **进程检测优化**
   - CSV格式输出（tasklist /FO CSV /NH）
   - UTF-8/GBK编码处理
   - 重试机制和缓存机制
   - 超时控制

3. **配置完整性校验**
   - JSON格式校验
   - 字段类型校验
   - 配置损坏时自动从config.lau.bak备份恢复
   - 恢复失败时重置为默认配置

4. **配置原子写入**
   - 先写入临时文件（tempfile.mkstemp）
   - fsync确保写入磁盘
   - os.replace原子替换原文件
   - 保存成功后自动创建.bak备份

5. **卸载残留文件处理**
   - 删除config.lau.bak、config.lau.corrupted
   - 删除acc.dat.bak
   - 删除*.tmp临时文件
   - 删除__pycache__目录

**性能优化（3项）**：
1. **启动卡顿修复**
   - 服务端状态检查移到后台线程（ServerCheckThread）
   - 减少进程检测重试次数
   - 减少tasklist和端口检查超时时间
   - 减少启动延迟时间

2. **控制台闪现修复**
   - subprocess调用添加CREATE_NO_WINDOW参数
   - 禁止创建控制台窗口
   - 启动时不再闪现黑色控制台

3. **管理员权限**
   - PyInstaller打包添加--uac-admin参数
   - launcher.exe和accmg.exe均以管理员权限运行
   - 子进程继承管理员权限
   - 解决DNF.exe启动需要提升权限的问题

## 重要技术决策

1. **运行库目录使用lib**：通过PyInstaller的--contents-directory lib参数实现，不使用默认的_internal
2. **管理员权限**：使用--uac-admin参数，确保可以正常启动DNF.exe
3. **Inno Setup打包**：多功能安装程序，支持安装/更新/卸载
4. **配置文件格式**：JSON格式，便于外部程序读取
5. **账号加密**：XOR加密+Base64编码，保护账号密码安全
6. **后台线程**：耗时操作使用QThread后台线程，避免阻塞UI
7. **单实例限制**：QSharedMemory互斥，防止多实例冲突
8. **GM工具默认MySQL**：避免未安装客户端补丁时数据库连接错误
9. **运行库实际文件夹**：使用实际文件夹复制方式，而非目录联接，提高稳定性
10. **运行库精简**：删除不需要的Qt模块，减小安装包体积
