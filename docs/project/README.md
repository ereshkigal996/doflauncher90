## 功能介绍

### 核心功能
1. **路径设置**：服务端和客户端路径配置，自动保存
2. **安装客户端补丁**：一键从服务端提取补丁安装到客户端
3. **账号系统**：账号登录、注册，密码安全传递
4. **游戏启动**：登录后自动启动服务端和客户端，支持双开
5. **服务管理**：一键停止服务端，自动检测运行状态
6. **GM工具**：直接启动服务端目录下的GM工具
7. **数据迁移**：数据库备份和恢复功能
8. **操作历史**：全局共享日志，实时记录重要操作
9. **账号管理**：独立的accmg账号管理工具，支持账号增删改查、分组管理、批量操作

### 2.0版本新增功能
10. **PVF文件校验**：启动服务前自动比对服务端与客户端的Script.pvf文件，可选择使用哪个版本，未选择的版本将被替换
11. **客户端路径自动同步**：每次启动服务端前，自动将启动器配置的客户端路径同步到服务端配置，避免服务端使用旧路径导致启动失败
12. **日志过滤机制**：自动隐藏端口信息、进程ID、服务端输出等内部操作记录，日志区仅显示重要用户操作
13. **全窗口圆角效果**：主窗口、PVF校验窗口、警告/确认/错误弹窗统一使用6px圆角

### 2.9版本新增功能
14. **accmg账号管理工具**：独立的账号管理程序，支持账号搜索、状态筛选、分组管理、批量操作、备注功能
15. **启动器性能优化**：移除重复导入、限制输出缓存大小、优化就绪信号检测逻辑
16. **服务端状态自动检测**：启动器打开时自动检测服务端状态，未启动时登录按钮显示为"启动服务"

### 界面特性
- 无边框窗口，自定义标题栏
- 双击标题栏最小化
- 深色主题，统一配色
- 按钮按下反馈效果
- 全窗口圆角设计

## 使用说明

### 首次使用
1. 启动程序后进入路径设置页面
2. 选择**服务端路径**（DNF90 服务端根目录）
3. 选择**客户端路径**（DNF 客户端目录，dnf.exe 所在目录）
4. 点击"确认"保存路径并进入主页面
5. 如需安装补丁，点击"安装客户端补丁"

### 日常使用
1. 启动程序后直接进入主页面
2. 点击"账号登录"进入登录页面
3. 输入账号和密码，点击"登录"
4. 程序自动同步客户端路径并启动服务端
5. 如检测到PVF文件不一致，会弹出校验窗口供选择
6. 服务端启动成功后自动启动客户端
7. 游戏结束后，点击"停止服务"安全关闭

### PVF文件校验
1. 启动服务前自动检测服务端与客户端的Script.pvf文件
2. 如文件不一致（大小或修改时间不同），弹出PVF校验窗口
3. 窗口显示两个版本的文件信息（路径、大小、修改时间）
4. 选择"使用服务端版本"或"使用客户端版本"
5. 未选择的版本将被选择的版本替换
6. 替换完成后自动继续启动服务端

### 数据备份
1. 在主页面点击"数据迁移"
2. 选择"数据保护"进行备份
3. 备份文件保存在 `backup` 文件夹
4. 需要恢复时，选择"数据恢复"
