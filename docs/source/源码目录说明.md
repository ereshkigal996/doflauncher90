## 各目录说明

### launcher/
启动器相关源码，包含主程序、安装程序和程序图标。

**主要文件**：
- `launcher_with_login.py`：启动器主源码，包含所有启动器功能
- `launcher_setup.py`：启动器安装程序源码
- `DFO.ico`：程序主图标

### gmtool/
GM工具相关源码，包含主程序、打包配置和物品数据。

**主要文件**：
- `gm_tool.py`：GM工具主源码，包含角色管理、背包管理、道具发放、邮件系统等功能
- `gmtool.spec`：GM工具打包配置（onedir模式）
- `gmtool_onedir.spec`：GM工具onedir打包配置（备用）
- `items.json`：物品数据文件（从PVF解析得到）
- `gmtool_strings.txt`：GM工具字符串文件

### accmg/
账号管理工具相关源码，包含主程序和打包配置。

**主要文件**：
- `account_manager.py`：账号管理工具主源码，包含账号增删改查、分组管理、批量操作等功能
- `accmg.spec`：账号管理工具打包配置

### analysis/
分析脚本目录，包含各种数据库分析、PVF解析、黑钻研究等脚本。

**主要脚本类型**：
- `analyze_*.py`：分析脚本，用于分析各种数据
- `query_*.py`：查询脚本，用于查询数据库表结构和数据
- `monitor_*.py`：监控脚本，用于监控数据库变更
- `deep_analyze_*.py`：深度分析脚本，用于深入分析特定问题
- `start_and_monitor_*.py`：启动并监控脚本，用于启动服务并监控
- `pvf_parser.py`：PVF解析器，用于解析PVF文件

### tests/
测试脚本目录，包含各种功能测试脚本。

**主要脚本类型**：
- `test_*.py`：测试脚本，用于测试各种API和功能
- `get_admin_page.py`：获取管理页面脚本，用于获取GM工具的管理页面

### common/
公共资源和其他文件目录，包含HTML页面、JSON数据、日志文件和已弃用的图标。

**主要文件**：
- `admin_page.html`：GM工具管理页面HTML
- `black_diamond_db_changes.json`：黑钻数据库变更记录
- `full_query_result.txt`：完整查询结果
- `gm_operations.log`：GM操作日志
- `gm_tool_changes.json`：GM工具变更记录
- `gm_tool_full_changes.json`：GM工具完整变更记录
- `Arrow-Left.ico`：返回按钮图标（已弃用）
- `Close.ico`：关闭按钮图标（已弃用）

### backup/
备份目录，用于存放各种备份文件。

### dist/
编译产物目录，包含三个程序的编译产物。

**子目录**：
- `launcher/`：启动器编译产物
- `gmtool/`：GM工具编译产物
- `accmg/`：账号管理工具编译产物

### dnf90_control_py/
DNF90Control相关源码，用于分析和研究DNF90Control程序。

### installer/
安装包脚本目录，包含所有Inno Setup安装脚本。

**主要文件**：
- `launcher_2.9.5_multifunction_installer.iss`：当前使用的多功能安装脚本（安装/更新/卸载）
- `launcher_2.9.5_installer.iss`：2.9.5普通安装脚本
- `launcher_2.8_final.iss`：2.8最终版安装脚本
- `launcher_installer.iss`：旧版安装脚本

## 打包命令

### 打包启动器
```bash
cd pip/launcher
pyinstaller launcher.spec --clean
```

### 打包GM工具
```bash
cd pip/gmtool
pyinstaller gmtool.spec --clean
```

### 打包账号管理工具
```bash
cd pip/accmg
pyinstaller accmg.spec --clean
```

### 打包安装包
```bash
"C:\Program Files\Inno Setup 7\ISCC.exe" pip/installer/launcher_2.9.5_multifunction_installer.iss
```

## 注意事项

1. **路径引用**：.spec文件中的路径引用已经更新为相对路径，打包时需要在对应的目录下执行命令。
2. **图标文件**：DFO.ico在launcher目录下，其他程序的.spec文件通过相对路径`../launcher/DFO.ico`引用。
3. **已弃用图标**：Arrow-Left.ico和Close.ico已经弃用，移到了common目录下。
4. **物品数据**：items.json文件较大（约74MB），是从PVF解析得到的物品数据。
5. **编译产物**：dist目录下的编译产物是最新版本，可以直接使用或复制到发布目录。
