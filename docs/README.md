## 文档管理规则

1. **所有项目文档** → 放在 `docs/project/` 目录
2. **所有源码文档** → 放在 `docs/source/` 目录
3. **所有版本更新说明** → 放在 `docs/version/` 目录
4. **所有参考文档** → 放在 `docs/reference/` 目录
5. **发布用文档** → 保留在 `release/launcher/` 目录（安装包需要）
6. **工作根目录** → 不直接创建任何文档文件
