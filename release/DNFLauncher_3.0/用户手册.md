## 简介

轮回登录器是一个专为90级单机版设计的多功能启动器，集成了账号管理、GM工具、客户端补丁安装、数据备份等功能，旨在提供便捷的单机游戏体验。

**主要特点：**
- 图形化操作界面，简单易用
- 一键启动服务端和客户端
- 内置账号注册与登录系统
- 多功能GM工具，支持角色管理、道具发放等
- 自动数据备份与恢复
- 支持自动更新

## 安装与配置

### 系统要求
- 操作系统：Windows 10 / Windows 11
- 运行环境：无需额外安装，程序自带运行库
- 权限要求：建议以管理员身份运行

### 首次使用配置

1. **启动程序**
   - 双击 `launcher.exe` 启动启动器
   - 首次启动会自动进入路径设置页面

2. **设置服务端路径**
   - 点击"浏览"按钮选择服务端根目录
   - 服务端目录应包含 `runtime` 文件夹

3. **设置客户端路径**
   - 点击"浏览"按钮选择客户端根目录
   - 客户端目录应包含 `.exe`

4. **安装客户端补丁**
   - 点击"安装客户端补丁"按钮
   - 等待补丁安装完成

5. **保存配置**
   - 点击"确认"按钮保存配置
   - 配置保存在 `config/config.lau` 文件中

### 配置文件说明

配置文件位于 `config/config.lau`，采用JSON格式，主要字段：

```json
{
  "launcher": {
    "server_path": "服务端路径",
    "client_path": "客户端路径",
    "server_type": "go",
    "last_account": "最近登录账号"
  },
  "gmtool": {
    "db_mode": "mysql",
    "last_character_id": "最近选择的角色ID"
  }
}
```

## 账号管理

### 注册账号

1. 点击首页"注册"按钮
2. 输入账号名（3-20位字符）
3. 输入密码（8-72位UTF-8字符）
4. 确认密码
5. 点击"注册"完成

**注意：**
- 账号名具有唯一性，不能重复
- 密码以加密形式存储在 `config/accounts.dat` 文件中
- 注册信息不会覆盖旧数据

### 登录账号

1. 在首页输入账号和密码
2. 点击"登录"按钮
3. 系统会自动验证账号密码
4. 验证成功后启动游戏客户端

**账号记忆功能：**
- 已登录过的账号会被记住
- 下次登录时可通过下拉菜单快速选择
- 密码自动填充

### 账号管理工具（accmg）

通过启动器首页或GM工具中的"账号管理"入口打开 `accmg.exe`，可以：
- 查看所有注册账号
- 修改账号密码
- 删除账号
- 批量管理账号

**特殊账号：**
- 在登录页面输入 `iamgod`（账号和密码均为iamgod）可启动账号管理工具

## 服务端管理

### 启动服务端

1. 确保服务端路径已正确设置
2. 点击"启动服务"按钮
3. 等待服务端启动完成（首次启动可能需要较长时间）
4. 状态栏显示"服务端已启动"表示成功

**服务端启动流程：**
1. 检查服务端路径配置
2. 检查PVF文件一致性
3. 启动MySQL数据库
4. 启动服务端主程序
5. 等待服务端就绪

### 停止服务端

1. 点击"停止服务"按钮
2. 系统会发送停止命令给服务端
3. 等待服务端完全停止
4. 如开启"关闭服务端时自动备份"，会先执行备份

**注意：**
- 停止服务端前建议先关闭游戏客户端
- 强制终止可能导致数据丢失

### 重启服务端

在"服务端设置"页面点击"重启服务端"按钮，系统会先停止服务端再重新启动。

### 服务端类型

启动器支持两种服务端类型：
- **第三方服务端（Go版）** - 原版服务端
- **一体式服务端（Python版）** - 自研服务端

在"服务端设置"页面可切换服务端类型，切换后需要重新设置对应路径。

## GM工具

GM工具（`gmtool.exe`）是一个多功能游戏管理工具，通过启动器首页的"打开GM工具"按钮启动。

### 主要功能模块

| 模块 | 功能说明 |
|-----|---------|
| **角色管理** | 查看角色列表、调整等级、删除角色、清理已删除数据 |
| **道具发放** | 搜索物品、发放道具、调整金币/点券 |
| **背包管理** | 查看角色背包、管理物品 |
| **邮件管理** | 查看邮件、删除邮件 |
| **装备管理** | 查看和管理角色装备（暂未开放） |
| **工具设置** | 配置路径、数据库模式等 |

### 角色管理

**角色列表：**
- 只显示当前登录账号下的角色
- 显示角色ID、名称、等级、职业、转职阶段等信息
- 支持搜索角色名

**操作功能：**
- **调整等级** - 修改角色等级
- **开启黑钻** - 为角色开启黑钻会员
- **删除角色** - 软删除角色（可恢复）
- **清理已删除数据** - 彻底清除已删除角色的所有数据（不可恢复）

**转职阶段显示：**
- 未转职
- 已转职
- 已觉醒（一次觉醒）
- 二次觉醒

### 道具发放

**物品搜索：**
- 支持按物品ID搜索
- 支持按物品名称关键词搜索
- 支持按物品类型筛选
- 物品列表从PVF文件实时解析

**发放流程：**
1. 选择目标角色（默认选择上次操作的角色）
2. 搜索并选择物品
3. 设置物品数量
4. （可选）设置强化等级和异次元属性
5. 点击"发送"按钮
6. 物品通过游戏内邮件发放，角色上线后在邮箱领取

**强化与增幅：**
- 仅装备类物品可设置强化等级
- 不包括时装、宠物装备、称号
- 异次元属性可选择力量、智力、体力、精神
- 强化等级和异次元数值可联动

**调整金币/点券：**
- 点击"调整金币"按钮，输入数值增加金币
- 点击"调整点券"按钮，选择充值/回收并输入数值
- 可在"预设"中设置默认方向（增加/充值）

### 背包管理

- 查看角色背包中的所有物品
- 显示物品ID、名称、类型、数量
- 物品名称和类型自动翻译
- 支持按类型筛选

### 邮件管理

- 查看角色收到的所有邮件
- 显示发件人、主题、内容、附件
- 支持批量删除邮件
- 删除操作通过上方按钮统一执行

### 工具设置

- **服务端路径** - 设置服务端根目录
- **客户端路径** - 设置客户端根目录
- **数据库模式** - 选择MySQL或SQLite
- **PVF路径** - 高级设置，需凭证文件才能修改
- **预设配置** - 设置金币/点券默认调整方向

## 数据备份与恢复

### 备份功能

启动器提供完整的数据备份功能，保护你的游戏进度。

**备份类型：**
- **手动备份** - 用户主动创建的备份，永久保留
- **自动备份** - 定时自动创建，保留最近20个
- **重要备份** - 标记为重要的备份，永久保留

**备份存储：**
- 备份文件按账号分目录存储：`backup/<用户名>/`
- 旧版备份自动迁移到 `backup/default/` 目录
- 备份文件名包含时间戳，便于识别

### 创建备份

1. 进入"存档管理"页面
2. 点击"创建备份"按钮
3. 输入备份备注（可选）
4. 等待备份完成

**注意：**
- 建议在停止服务端后创建备份，确保数据一致性
- 备份包含数据库文件和角色数据

### 恢复备份

1. 进入"存档管理"页面
2. 在备份列表中选择要恢复的备份
3. 双击备份或点击"恢复"按钮
4. 确认恢复操作
5. 等待恢复完成

**警告：**
- 恢复备份会覆盖当前所有数据
- 恢复前建议先创建当前数据的备份
- 恢复操作不可撤销

### 自动备份设置

在"存档管理"页面点击"设置"按钮，可配置：

1. **定时备份**
   - 开启/关闭定时备份
   - 设置备份间隔（分钟/小时/天）

2. **关闭服务端时自动备份**
   - 开启后，每次停止服务端时自动创建备份
   - 备份完成前禁止关闭程序
   - 备份类型标记为"自动"

### 备份管理

- **查看备份列表** - 显示所有备份，包含名称、类型、创建时间、大小、备注
- **删除备份** - 选中备份后点击删除
- **标记重要** - 将备份标记为重要，自动清理时不会被删除
- **编辑备注** - 修改备份的备注信息

**备份类型颜色标识：**
- 手动备份 - 白色
- 自动备份 - 灰色
- 重要备份 - 金色

## 常见问题

### 1. 启动器无法启动服务端？

**可能原因及解决方法：**
- 检查服务端路径是否正确设置
- 确认服务端文件完整，未被杀毒软件删除
- 尝试重启电脑后再次启动（Win11系统可能出现端口占用bug）
- 确认以管理员身份运行启动器
- 检查服务端主体程序（`/runtime/bin`）是否被修改，如修改时间距今小于1天，启动器会自动检测 `instance.json`

### 2. 游戏启动后显示"服务器连接不上"？

**可能原因及解决方法：**
- 确认服务端已成功启动（状态栏显示"服务端已启动"）
- 检查服务端IP配置是否正确（默认127.0.0.1）
- 确认防火墙未阻止游戏进程
- 检查客户端补丁是否正确安装
- 尝试重新安装客户端补丁

### 3. 无法登录账号？

**可能原因及解决方法：**
- 确认数据库已正常启动（服务端启动时会自动启动）
- 检查账号密码是否正确（注意大小写）
- 尝试重新注册账号
- 检查 `config/accounts.dat` 文件是否存在且未损坏
- 确认数据库类型选择正确（MySQL/SQLite）

### 4. 登录提示"权限不足"？

**可能原因及解决方法：**
- 确认以管理员身份运行启动器
- 右键点击 `launcher.exe`，选择"以管理员身份运行"
- 检查服务端目录是否有写入权限

### 5. 安装客户端补丁失败？

**可能原因及解决方法：**
- 确认客户端路径设置正确（应包含 `.exe`）
- 确认游戏已完全退出（检查任务管理器中是否有 `.exe` 进程）
- 尝试以管理员身份运行启动器
- 检查客户端目录是否有写入权限
- 临时关闭杀毒软件后重试

### 6. 服务端启动超时？

**可能原因及解决方法：**
- 首次启动可能需要较长时间（60秒超时），请耐心等待
- 检查MySQL服务是否正常启动
- 确认服务端配置文件（`instance.json`）正确
- 检查端口是否被其他程序占用
- 尝试重启电脑后再次启动

### 7. GM工具无法连接数据库？

**可能原因及解决方法：**
- 确认服务端已启动（GM工具需要服务端的数据库支持）
- 检查数据库配置是否正确
- 确认数据库类型选择正确（MySQL默认端口13306）
- 检查 `config/config.lau` 中的配置是否正确
- 尝试在GM工具的"工具设置"中重新配置路径

### 8. GM工具中看不到角色？

**可能原因及解决方法：**
- GM工具只显示当前登录账号下的角色
- 确认你已在启动器中登录对应账号
- 确认该账号下确实有创建角色
- 尝试刷新角色列表
- 检查数据库中角色数据是否存在

### 9. 道具发放后收不到邮件？

**可能原因及解决方法：**
- 确认角色已正确选择
- 检查物品ID和数量是否正确
- 确认服务端正在运行
- 游戏内需要重新登录角色才能看到新邮件
- 检查邮箱是否已满
- 部分特殊物品可能无法通过邮件发放

### 10. 数据备份失败？

**可能原因及解决方法：**
- 确认服务端已停止（备份时建议停止服务端）
- 检查备份目录（`backup/`）是否有足够空间
- 确认数据库文件未被其他程序占用
- 检查 `backup/` 目录是否有写入权限
- 尝试手动创建备份目录

### 11. 启动器闪退？

**可能原因及解决方法：**
- 确认运行库文件完整（`lib/` 目录）
- 尝试以管理员身份运行
- 检查是否有杀毒软件拦截
- 确认配置文件（`config/config.lau`）格式正确
- 尝试删除配置文件后重新配置
- 检查服务端是否未正常关闭（可能导致下次启动闪退）

### 12. 更新程序无法检查更新？

**可能原因及解决方法：**
- 确认网络连接正常
- 检查Gitee仓库是否可访问
- 确认当前版本号已正确写入程序属性
- 检查更新服务器配置是否正确
- 尝试手动下载最新版本

### 13. 账号密码忘记了怎么办？

- 账号信息加密存储在 `config/accounts.dat` 文件中
- 如忘记密码，可使用账号管理工具（accmg）查看或修改
- 在登录页面输入 `iamgod`（账号密码均为iamgod）可启动账号管理工具
- 也可以直接删除 `config/accounts.dat` 文件重新注册（会丢失所有已保存账号）

### 14. 如何切换服务端类型？

1. 进入"服务端设置"页面
2. 在服务端类型下拉菜单中选择"第三方服务端"或"一体式服务端"
3. 设置对应服务端的路径
4. 点击"保存"按钮
5. 重启启动器使配置生效

### 15. PVF文件不一致怎么办？

- 启动服务端时会自动校验服务端与客户端的PVF文件
- 如不一致，会弹出PVF替换工具窗口
- 可选择使用服务端PVF或客户端PVF
- 选择后，未选择的PVF会被替换
- 建议备份原始PVF文件后再操作
