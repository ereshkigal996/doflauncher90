# 轮回登录器

## 简介
轮回登录器是一个专为90级单机版设计的多功能登录器，集成了账号管理、GM工具、客户端补丁安装等功能。

**当前版本：3.2.0**
**适用范围：单机版**

## 主要功能
- 一键启动游戏
- 账号注册与登录
- 服务端管理（启动/停止/重启）
- 客户端补丁安装
- PVF文件校验与替换
- 数据备份与恢复（支持按账号分目录存储）
- GM工具（角色管理、背包管理、道具发放、邮件管理等）
- 账号管理工具
- 自动更新

## 目录结构
```
Launcher/
├── launcher.exe          # 登录器主程序
├── updater.exe           # 自动更新程序
├── config/               # 配置文件目录
│   ├── config.lau        # 主配置文件
│   └── accounts.dat      # 账号保管文件
├── lib/                  # 运行库（launcher和updater共用）
├── backup/               # 数据备份目录（按账号分目录存储）
└── module/               # 模块目录
    ├── accmg.exe         # 账号管理工具
    ├── gmtool.exe        # GM工具
    └── lib/              # 模块运行库
```

## 快速开始
1. 首次运行请设置服务端路径和客户端路径
2. 安装客户端补丁
3. 启动服务端
4. 注册账号并登录游戏
